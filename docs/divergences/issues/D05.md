## Resumo
Com `extern "C" { fn floor(x: f64) -> f64 }`, Madaros imprime `A`, `7`, `B`; `lean_single` imprime só `A` e encerra sem mensagem (`souc run` sai com rc 1).

## Programa mínimo
```
extern "C" { fn floor(x: f64) -> f64 }
fn main() -> i32 with IO, Mut, Div, Panic, Alloc {
    print("A\n")
    print_int(floor(7.9) as i64)
    print("\n")
    print("B\n")
    return 0
}
```

## Comandos
```bash
bin/souc run D05.sio                                   # A / 7 / B
SOUNIO_SOUC_ENGINE=lean_single bin/souc run D05.sio    # A   (e para)
```
Relacionado: #983, #932 (cast f64→i64).
