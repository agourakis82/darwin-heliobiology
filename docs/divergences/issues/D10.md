## Resumo
`struct G { mu: f64, var: f64 }` com `G { mu: 1.0, var: 2.0 }` e `g.var` compila e roda em Madaros e falha em `lean_single` (`missing field in struct literal`, `unknown field access`). Ou o parser do Madaros deve rejeitar palavras-chave como identificador de campo, ou o do `lean_single` deve aceitar — hoje é um motivo silencioso de código que só roda num motor.

## Programa mínimo
```
fn main() -> i32 with IO, Mut, Div, Panic, Alloc {
    var g = G { mu: 1.0, var: 2.0 }
    print_f64(g.var)
    print("\n")
    return 0
}
struct G { mu: f64, var: f64 }
```

## Comandos
```bash
bin/souc run D10.sio                                  # 2.000000
SOUNIO_SOUC_ENGINE=lean_single bin/souc run D10.sio   # error: missing field in struct literal at <main>:4 / unknown field access at <main>:5
```

**Ambiente (medido em 2026-10-06):** Linux x86_64, `origin/main` `4871d3fa0`, `bin/souc` = `Madaros v0.80.0` (o ELF prebuilt commitado, "not built from the tree"), `SOUNIO_STDLIB_PATH=$PWD/stdlib`, `lean_single` via `SOUNIO_SOUC_ENGINE=lean_single`.
