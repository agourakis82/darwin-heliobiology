## Resumo
No Madaros, funções que chamam `read_file`/`print` sem `with IO` e um helper que reatribui uma `var` local sem `with Mut` passam em `souc check` e rodam. `lean_single` rejeita todos com `error[E035]: effect not declared in function signature`. O CLAUDE.md pede "Efeitos declarados"; com Madaros isso não é verificado para esses dois efeitos, então um código pode parecer correto no `check` e falhar no outro motor.

## Programa mínimo
```
fn bump(s: i64) -> i64 {
    var z = s
    z = z + 1
    z
}
fn slurp(path: string) -> i64 {
    str_len(read_file(path))
}
fn shout() {
    print("hi\n")
}
fn main() -> i32 with IO, Mut {
    print_int(bump(2))
    print("\n")
    return 0
}
```

## Comandos
```bash
bin/souc check D11.sio                                  # check: OK
SOUNIO_SOUC_ENGINE=lean_single bin/souc check D11.sio   # error[E035] ... line 7, 11, 14
```
O darwin-heliobiology declara os efeitos corretamente (29 arquivos) justamente porque o `lean_single` os exige; o gate roda os testes nos dois motores.

**Ambiente (medido em 2026-10-06):** Linux x86_64, `origin/main` `4871d3fa0`, `bin/souc` = `Madaros v0.80.0` (o ELF prebuilt commitado, "not built from the tree"), `SOUNIO_STDLIB_PATH=$PWD/stdlib`, `lean_single` via `SOUNIO_SOUC_ENGINE=lean_single`. Achado durante a reescrita do núcleo de cálculo do darwin-heliobiology em Sounio (ADR-008/ADR-009).
