## Resumo
`struct Box { v: f64, n: i64 }` passa em `souc check` e em `souc run` compila, mas o programa termina com SIGSEGV (rc 139) assim que o campo é usado. Renomear o struct (por exemplo `Bx`) corrige. `lean_single` imprime o resultado correto. Nenhum diagnóstico de colisão com o builtin `Box`.

## Programa mínimo
```
struct Box { v: f64, n: i64 }
fn main() -> i32 with IO, Mut, Div, Panic, Alloc {
    var b = Box { v: 0.0, n: 0 }
    b.v = 2.5
    print_f64(b.v)
    print("\n")
    return 0
}
```

## Comandos
```bash
bin/souc check D04.sio                                  # check: OK
bin/souc run D04.sio                                    # Segmentation fault
SOUNIO_SOUC_ENGINE=lean_single bin/souc run D04.sio     # 2.500000
```
Custou uma bissecção: com `struct P { ... }` o mesmo programa roda. Pedido: erro de compilação "nome já definido como builtin" (ou isolar o namespace do usuário).

**Ambiente (medido em 2026-10-06):** Linux x86_64, `origin/main` `4871d3fa0`, `bin/souc` = `Madaros v0.80.0` (o ELF prebuilt commitado, "not built from the tree"), `SOUNIO_STDLIB_PATH=$PWD/stdlib`, `lean_single` via `SOUNIO_SOUC_ENGINE=lean_single`. Achado durante a reescrita do núcleo de cálculo do darwin-heliobiology em Sounio (ADR-008/ADR-009).
