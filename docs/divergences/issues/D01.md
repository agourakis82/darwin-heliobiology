## Resumo
O mesmo programa de 9 linhas dá resultados diferentes nos dois motores. Madaros imprime `1934872821` (confere com aritmética de inteiros de precisão arbitrária); `lean_single` imprime `-212610827`.

## Programa mínimo
```
fn main() -> i32 with IO, Mut, Div, Panic, Alloc {
    var s: u64 = 88172645463325252
    let m: u64 = 0x2545F4914F6CDD1D
    s = s ^ (s >> 12)
    s = s ^ (s << 25)
    s = s ^ (s >> 27)
    let r: u64 = s * m
    print_int((r >> 33) as i64)
    print("\n")
    return 0
}
```

## Comandos
```bash
bin/souc run D01.sio                                   # 1934872821
SOUNIO_SOUC_ENGINE=lean_single bin/souc run D01.sio    # -212610827
```
Esperado (Python, só como conferência): `s=88172645463325252; s^=s>>12; s^=(s<<25)&M; s^=s>>27; ((s*0x2545F4914F6CDD1D)&M)>>33 == 1934872821`.
